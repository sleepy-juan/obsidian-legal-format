# Legal Format

한국 법률 조문 텍스트를 Obsidian 마크다운으로 포맷하는 플러그인입니다.

## 기능

### 커맨드

| 커맨드 | 설명 |
|---|---|
| **법률 조문 포맷** | 조문 구조에 맞게 마크다운 포맷 적용 |
| **법률 조문 포맷 - Clean** | 위 기능 + `<개정 ...>`, `[전문개정 ...]` 등 주석/메타정보 제거 |

`Cmd+P` (Windows: `Ctrl+P`)로 커맨드 팔레트를 열고 `법률 조문 포맷`을 검색하여 실행합니다.

### 포맷 규칙

| 요소 | 규칙 | 예시 |
|---|---|---|
| 편 | `# heading` | `# 제1편 총칙` |
| 장 | `## heading` | `## 제1장 통칙` |
| 절 | `### heading` | `### 제1절 능력` |
| 관 | `#### heading` | `#### 제1관 통칙` |
| 부칙 | `## heading` | `## 부칙` |
| 조 | **bold** + blockquote | `> **제1조(목적)** 내용...` |
| 호 | inline code | `` > `1.` 내용 `` |
| 목 | inline code | `` > `가.` 내용 `` |
| 항 번호 | 뒤에 공백 삽입 | `①제1항...` → `① 제1항...` |
| 빈 줄 | 제거 | 복사/붙여넣기로 생긴 빈 줄 정리 |

### Clean 버전 추가 제거 대상

- `<개정 2020.1.1.>`, `<신설 ...>`, `<삭제 ...>` 등 angle bracket 주석
- `[전문개정 ...]`, `[본조신설 ...]`, `[제목개정 ...]` 등 bracket 주석
- `[시행 2024.1.18.] [법률 제19898호, ...]` 등 메타정보 라인 전체
- `[시행일: 2026. 5. 11.] 제2조` 등 시행일 라인 전체

## 예시

### 입력 (원본 텍스트)

```
민법
[시행 2024.1.18.] [법률 제19898호, 2024.1.16., 일부개정]

제1편 총칙

제1장 통칙

제1조(법원) 민사에 관하여 법률에 규정이 없으면 관습법에 의하고 관습법이 없으면 조리에 의한다. <개정 2014. 12. 30.>
[전문개정 2012. 2. 10.]
제2조(신의성실) ①권리의 행사와 의무의 이행은 신의에 좇아 성실히 하여야 한다.
②권리는 남용하지 못한다.

제2장 인

제1절 능력

제3조(권리능력의 존기) 사람은 생존한 동안 권리와 의무의 주체가 된다.
제4조(성년) 사람은 19세로 성년에 이르게 된다. <개정 2011. 3. 7.>
제5조(미성년자의 능력) ①미성년자가 법률행위를 함에는 법정대리인의 동의를 얻어야 한다.
1. 권리만을 얻거나 의무만을 면하는 행위
2.처분이 허락된 재산의 처분행위
가. 용돈의 처분
나.허락된 영업에 관한 행위
```

### 출력: 법률 조문 포맷

```markdown
민법
[시행 2024.1.18.] [법률 제19898호, 2024.1.16., 일부개정]
# 제1편 총칙

## 제1장 통칙

> **제1조(법원)** 민사에 관하여 법률에 규정이 없으면 관습법에 의하고 관습법이 없으면 조리에 의한다. <개정 2014. 12. 30.>
> [전문개정 2012. 2. 10.]

> **제2조(신의성실)** ① 권리의 행사와 의무의 이행은 신의에 좇아 성실히 하여야 한다.
> ② 권리는 남용하지 못한다.

## 제2장 인

### 제1절 능력

> **제3조(권리능력의 존기)** 사람은 생존한 동안 권리와 의무의 주체가 된다.

> **제4조(성년)** 사람은 19세로 성년에 이르게 된다. <개정 2011. 3. 7.>

> **제5조(미성년자의 능력)** ① 미성년자가 법률행위를 함에는 법정대리인의 동의를 얻어야 한다.
> `1.` 권리만을 얻거나 의무만을 면하는 행위
> `2.` 처분이 허락된 재산의 처분행위
> `가.` 용돈의 처분
> `나.` 허락된 영업에 관한 행위
```

## 설치

1. 이 저장소를 빌드하거나, Releases에서 `main.js`와 `manifest.json`을 다운로드합니다.

2. Obsidian Vault의 플러그인 폴더에 복사합니다:

   ```bash
   mkdir -p <Vault경로>/.obsidian/plugins/legal-format
   cp main.js manifest.json <Vault경로>/.obsidian/plugins/legal-format/
   ```

3. Obsidian을 재시작합니다.

4. **Settings > Community plugins** 에서 Restricted mode를 끄고, **Legal Format** 플러그인을 활성화합니다.

## 빌드

```bash
npm install
npm run build
```
